# Poster-Dateien

Lege hier deine Poster als **PNG oder JPG** ab, Dateiname = Produkt-Handle aus Shopify
(z. B. `berge-im-morgenlicht.png`). Mindestens 1 500 px lange Kante; für Mockups reicht eine
Web-Auflösung, Druckdateien sind nicht nötig.

Das Studio sucht hier nach Motiven für Mockups, Karussell-Slides und Clips. Fehlt eine Datei,
rendert es einen Marken-Platzhalter und legt dir eine Karte „Poster-Dateien ablegen“ auf den
Schreibtisch.
