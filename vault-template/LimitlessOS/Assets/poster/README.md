# Poster-Dateien

**Du musst hier nichts ablegen.** Das Studio nutzt die Produktbilder direkt aus Shopify – die Links
stehen in `Marke/Produkte.md` (Spalte „Bild-URL“). Für 113 Produkte ist das das reine Motiv ohne Rahmen
(ideal für Mockups), für die 12 Printify-Importe ein bereits gerahmtes Mockup.

Optional: Liegt hier eine Datei `<handle>.png` oder `<handle>.jpg` (Dateiname = Produkt-Handle aus
Shopify, z. B. `the-world-is-yours-motivationsposter.png`), nimmt das Studio sie **bevorzugt** –
sinnvoll, wenn du eine höher aufgelöste Druckdatei oder eine Variante ohne Mockup hast.
Mindestens 1 500 px lange Kante.
