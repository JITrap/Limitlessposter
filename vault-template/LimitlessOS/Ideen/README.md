# Ideen

Hier sammeln Planer und Content-Studio Poster-Motive, Kampagnen und Post-Ideen ohne Termin.
Eine Idee = eine Notiz mit Frontmatter `type: idee`, `status: offen | geplant | verworfen`,
`quelle: trend | kennzahl | julius`. Du kannst jederzeit eigene Ideen als Notiz hier ablegen –
der Planer liest sie beim nächsten Lauf.
