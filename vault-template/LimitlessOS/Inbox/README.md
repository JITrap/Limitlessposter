# Inbox – hier wirfst du Dinge rein

Alles, was du dem System geben willst, legst du als Datei in diesen Ordner:

- den kopierten **Chat mit deiner Tagesplanung** (als `.md` oder `.txt`),
- Regeln, Ideen, Wettbewerber-Links, Kundenfeedback,
- Beschreibungen neuer **Skills oder Stationen**, die das System lernen soll.

Der Aufseher legt für jede neue Datei eine Planer-Aufgabe „Inbox einordnen“ an. Der Planer
überträgt den Inhalt an die richtige Stelle (Marke, Strategie, Ideen) und legt Folgeaufgaben an.
Die Datei bleibt liegen und bekommt oben einen Vermerk „Eingeordnet am …“.

Diese README wird ignoriert.
