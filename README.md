# Limitless OS

Lokales „Firmen-Betriebssystem“ für die Marke **Limitless Poster**: KI-Arbeiter
(Claude Code) arbeiten an Stationen an der Marke, ein Aufseher verteilt die
Arbeit und hält das Abo-Budget ein, der Obsidian-Vault ist das Gehirn.

- Spezifikation: `docs/superpowers/specs/2026-10-22-limitless-os-design.md`
- Umsetzungsplan: `docs/superpowers/plans/2026-10-22-limitless-os-phase1.md`

Entwicklung: `npm run install:all && npm test`
